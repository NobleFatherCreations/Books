THE FESTIE BIBLE — TELEPROMPTER SCRIPTS
21 guides · 270 scenarios · plus a series intro and a series outro

WHAT'S IN HERE
One markdown file per guide. Each file contains, in order:
  1. The guide's INTRO EPISODE — what the acronym stands for, why the guide
     exists, and what's coming up in it.
  2. Every scenario in that guide, in order, each as its own episode.
  3. The guide's CLOSING EPISODE — the whole guide pulled back into one piece.

Plus two standalone files:
  00-SERIES-INTRO.md — the welcome to the whole Festie Bible
  00-SERIES-OUTRO.md — the close of the whole series

EVERY SCENARIO FOLLOWS THE SAME SPOKEN SHAPE
  Who this is about → the scene, told as a story → a comedic beat calling out
  the behaviour → what to watch for → what's really going on → the check to run
  → the harder truth underneath → the move → the exact words to say → the truth
  to end on.

Everything is written to be read aloud to a camera. Full sentences, spoken
rhythm, contractions, connectives. No bullet fragments.
