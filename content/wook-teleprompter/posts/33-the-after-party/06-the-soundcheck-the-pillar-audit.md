## The Soundcheck — The Pillar Audit

One final drill.

Five questions. One minute each.

1. Can you run the Known Perimeter right now? Government names, ICE contacts, meet-up spot, code word, dose plan if applicable. If yes: the perimeter is standing. If no: fifteen minutes before your next event.

2. Name three people in your Vetted Community. First and last names. If you can: the community is built. If you can’t name three: which one relationship could you deepen in the next three months?

3. Name two non-scene things you are currently doing for your own enjoyment. Not things you used to do. Current. If you can: the floor is there. If you can’t: what is the one thing you could start this week?

4. When was the last time you did a post-event behavioral scan? If within the last event: the practice is active. If longer: resume it after the next event.

5. When did you last pass something forward? If you can name it: the pillar is active. If you can’t: is there something in your possession right now that belongs to someone who needs it?

Five questions. Five minutes. The architecture that holds.
