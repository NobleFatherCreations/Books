## The Soundcheck — The Pre-Show Capacity Plan

Run this before the event. Sober. With your crew.

1. Tonight’s Dose Plan. Write the actual substances and amounts. Include “none” if none. Include time windows. Include interactions you are watching for.

2. Tonight’s Anchor. Name. Sober hours. Backup anchor. Code word. The code word means: “come to me now, no questions.”

3. Tonight’s Limits. What you will not consent to tonight regardless of state. Write them:

No new sexual partners.

No new financial agreements.

No substances from strangers.

No leaving the grounds without anchor contact.

No solo afters.

4. Tonight’s Exit. Ride. Tent location. Phone charge plan. Cash on body. Anchor’s number written in pen on your forearm if the phone dies.

5. Tomorrow’s Debrief. Time and place where the crew checks in. What worked. What didn’t. What changes at the next event.

Scoring:

**Green:** All five filled, shared with crew, agreed to.

**Yellow:** Some written, some assumed.

**Red:** “We’ll figure it out.”

Red goes to the tent. The tent runs the festival differently.
