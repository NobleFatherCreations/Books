# Combo Clusters: public Markdown (Corporate and Entertainment)

313 Markdown files: `CORP/` (149) and `ENT/` (164). One file per script, plus one sector-standards file and one introduction file per category in each folder. Public edition: no review labels, no delivery cues, no credibility audit section. Each script uses one spelling convention (US or UK) throughout.

## Loading them
- `index.json` lists every file: `id`, `sector`, `file`, `type` (combo | category_intro | standards), and for scripts `title`, `category`, `tactics` (in order) and `standard`.
- Each file has YAML front matter, a `# title` line, then `## Section` headings. Split on `## `. Bold lines, bullet lists and Markdown tables are used; no HTML.
- `standard: v3` is the new standard. All 138 Corporate scripts are v3 (plus one Entertainment script, ENT-C113). A v3 script has: `Before the Story` (intro page, first), a longer Cold Open, `Why This Order` with one order sentence and one "Flip it:" line per tactic, `Why the System Produces This Order`, `On Purpose`, and `Where Each Tactic Happened` (a table). `v2` is the earlier standard (the shorter original story plus order sentences and "Flip it" lines); every Entertainment script except ENT-C113 is v2.
- Story first: do not show the script's title or tactic list above the Cold Open. The intro page and the story deliberately do not name the pattern; the name arrives at `The Name` after the story.

## What was checked
Every v3 script passed program checks: all tactics present and in order, scene headings matching the quoted acts, banned wording, brands, lengths, one spelling convention, repeated names, Flip lines not copying the next box. A strict reader has read 14 of the 138 Corporate scripts in full or in part; the rest are program-checked only. Known open points are in `REVIEW_NOTES.md`.

Educational pattern-recognition material, not advice. Safety Notes inside a script apply wherever it is shown.
