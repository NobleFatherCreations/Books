# PHONE-CHECK: Fractal² intro v7 (do on a real iPhone Safari and a mid Android Chrome)
1. Open the preview link on mobile data, not Wi-Fi. Title and "Begin" should appear almost at once; the gold rings fade in within a few seconds.
2. Rotate to landscape and back; the layout should change, the page should not jump to a different place.
3. Scroll slowly through the first screens: the view should start deep inside the diagram and pull back with no stutter.
4. At "Then I looked closer" the black bars slide in and the large diagram should fill the screen width, with no hard edge.
5. Scroll fast to the bottom and back to the top; nothing should stay half-faded; the caption in the header should match what you see.
6. Pull the address bar up and down; the diagram must not resize or jump.
7. Tap Leave: the page should be replaced by a neutral website at once. Press Back: it should not return to the story.
8. Turn on Reduce Motion (Settings > Accessibility > Motion): the zoom should become simple steps, no drifting.
9. Increase text size (Settings > Display > Text Size): text should grow and stay inside the screen.
10. Turn VoiceOver on: swipe through; headings should read in order (Fractal², The room, The shape ...), the Leave button should be named, decorative parts should be silent.
Report anything that jerks, tears, goes blank, or is hard to read.
